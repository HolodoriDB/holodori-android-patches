# holodori-android-patches
***Manually*** updated Android patches for the game hololive Dreams that disable Google Play requirement and enable mitm debugging

## Check the Releases
We provide APKs of the game that disables the Google Play dependency. These patched versions also enables MITM debugging (disabling certificate validation).

The game still does require an Android API version of 29+ (or Android 10+) and a compatible device - this only bypasses Google Play requirment and not any other device requirements.

### Working Emulators
- LDPlayer 14

If you spot any other emulators that work, please open an issue and inform us!

NOTE: despite some emulators supporting Android API 29+ it appears most still don't support specific graphic APIs required by the game.

Regardless of precautions taken and relatively harmless modifications, this is a modified version of the game and there is a low chance of getting banned.
